# Completed Records and browser report access — 13 November 2026

The website now includes Completed Records, linked from the main navigation and completed summary card. It lists completed gross/tare entries, their net weights, completion dates, search and date filters, and a Download report action per entry. Individual downloads use the same inward-cargo template as Report studio: reference field order, gold Donito logo and surveyor section. All 16 reference data fields populate from the selected saved entry without report-field input. Missing or whitespace-only values display N/A, valid zero values are preserved, and canonical field slugs take priority over legacy field names. Blank duplicate fields cannot hide saved legacy values. Surveyor checkboxes, name and signature lines remain manual.

Report authorization no longer has a separate 15-minute timeout. Account password confirmation issues an opaque per-tab token held only in sessionStorage; the server stores its hash, user identity and current password stamp. Protected report requests require this token in a header or POST field, never a URL. Last report login displays the latest confirmation in the current signed-in session. Account-session expiration, logout or a password change still requires fresh authorization.

Internal website navigation preserves access. Closing or reloading clears the token and sends a best-effort server revocation beacon. A normal new tab has no report grant. Browser crashes, forced termination and session restore are outside reliable page-lifecycle guarantees; verify the client's browser restore policy. No extra report expiry has been introduced. Desktop PDF downloads remain disabled, including the old API endpoint; no desktop reinstall is required for this website release.
